# WABBIT EARS

a whole TV network, channel-surfing and all, that runs on your own computer.

- **watch it live:** https://wabbitears.com
- **get the app:** the newest release on this page (Windows and Linux · Mac coming later)
- **shows come in packs:** the app starts with an empty set and pulls the newest pack from here. one file, every channel.

`latest.json` is the feed the app reads: the newest pack and the newest app version.
